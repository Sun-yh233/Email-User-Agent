# Email User Agent (邮件用户代理)

一个支持SMTP发送和POP3接收功能的跨平台邮件客户端，具有安全通信功能。

## 功能特性

- ✉️ **邮件发送**: 支持SMTP协议发送邮件
- 📬 **邮件接收**: 支持POP3协议接收邮件
- 🔐 **安全通信**: 基于共享密钥的端到端加密
- 🔄 **一次一密**: 每封邮件使用不同的编码表
- ✅ **消息认证**: HMAC-SHA256防篡改
- 🛡️ **防重放攻击**: 序列号机制防止重放和重复
- 📝 **MIME支持**: 完整的MIME邮件格式支持
- 📎 **附件支持**: 支持发送和接收附件，非文本附件（图片、音视频等）不加密
- 🎯 **收件中心模式**: 支持UA身份识别，区分配对UA和其他UA的邮件
- 🖼️ **智能加密**: 文本内容加密，多媒体内容保持原样便于服务器识别
- 🔧 **多服务器支持**: 兼容多种邮件服务器（QQ、163、Sina、中科院邮箱等）
- 🖥️ **跨平台**: 支持Windows和Linux系统
- 🎨 **图形界面**: 提供友好的GUI界面

## 系统要求

- Python 3.6+
- tkinter (通常包含在Python标准库中)

## 使用说明

### 配置邮箱账号

1. 启动程序后，点击"设置"菜单
2. 输入您的邮箱信息：
   - 邮箱地址
   - SMTP服务器地址
   - SMTP端口（通常为25、465或587）
   - POP3服务器地址
   - POP3端口（通常为110或995）
   - 授权码或密码

### 发送邮件

1. 点击"发送邮件"标签
2. 填写收件人地址、主题和正文
3. （可选）点击"添加"按钮添加附件
4. 点击"发送"按钮

### 接收邮件

1. 点击"接收邮件"标签
2. 点击"接收邮件"按钮
3. 邮件列表将显示收到的邮件
4. 点击邮件查看详细内容
5. 安全邮件会显示验证状态和邮件类型：
   - ✓ 已加密并验证 [配对UA] - 来自使用相同UA身份的邮件客户端
   - 🔒 来自其他UA [无法解密] - 来自使用不同UA身份的邮件客户端
   - 📧 普通邮件（未加密） - 来自其他邮件客户端的普通邮件

## 安全通信

### 配置安全邮件

1. 与通信对方约定一个共享密钥（建议16字符以上）
2. 打开"设置" -> "高级设置"
3. 勾选"启用自定义Base64编码"
4. 输入共享密钥
5. （可选）输入UA身份标识，留空则自动生成
   - 配对的UA需要使用相同的身份标识才能互相解密邮件
   - 用于实现"收件中心模式"，支持多个UA向同一收件箱发送加密邮件
6. 保存设置

### 安全特性

- **一次一密**: 每封邮件使用不同的编码表，即使一封被破解也不影响其他邮件
- **消息认证**: 使用HMAC-SHA256验证邮件完整性，防止篡改
- **防重放**: 序列号机制自动检测重复邮件
- **健壮性**: 支持邮件丢失、重复、乱序情况下的正常解密
- **透明加密**: 对用户透明，发送和接收与普通邮件无异
- **附件加密**: 文本类附件自动加密，多媒体文件保持原样
- **收件中心模式**: 支持多个UA共享收件箱，但只能解密配对UA的邮件
- **智能内容处理**: Base64编码时自动识别并保留图片、音视频等多媒体内容

详细说明请参考 [SECURITY_REPORT.md](SECURITY_REPORT.md)

## 安全实现

本项目实现了完整的端到端加密邮件系统：

### 核心技术
- **密钥派生**: HMAC-SHA256从共享密钥派生每封邮件的密钥
- **一次一密**: 每封邮件使用独立的Base64编码表
- **消息认证**: HMAC-SHA256保证邮件完整性
- **序列号机制**: 防止重放、重复和支持乱序
- **UA身份**: 支持收件中心模式，区分配对UA和其他UA
- **智能加密**: 文本内容加密，多媒体内容保持原样

### 收件中心模式

本系统支持"收件中心模式"，允许多个UA使用同一个收件箱，但只能解密配对UA的邮件：

1. **配对UA邮件**: 使用相同共享密钥和UA身份标识的邮件客户端，可以正常加密和解密邮件
2. **其他UA邮件**: 来自使用不同UA身份的邮件客户端，系统会识别出来并显示提示信息，无法解密
3. **普通邮件**: 来自其他标准邮件客户端的未加密邮件，正常显示

这个特性使得多个学生可以将邮件发送到同一个"收件中心账户"（如network@abc.com），但每个人只能查看与自己配对的UA发送的加密邮件。

### 智能内容处理

为了避免加密过程中对多媒体内容的干扰，系统实现了智能内容识别：

1. **文本内容**: 邮件正文（text/plain, text/html）进行完整加密
2. **文本附件**: 非多媒体类型的附件（如.txt, .doc等）进行加密
3. **多媒体附件**: 图片（.jpg, .png等）、音频（.mp3, .wav等）、视频（.mp4, .avi等）保持原样不加密
4. **MIME结构**: 邮件整体保持标准MIME格式，邮件服务器可以正常识别附件类型

这样设计的好处是：
- 邮件在服务器看来是正常的MIME邮件
- 可以看出邮件是否带有附件
- 可以看到邮件中的图片、LOGO等（如果作为附件）
- 但文本内容和文本附件仍然被加密保护

### 算法来源
- **HMAC-SHA256**: Python标准库`hashlib`和`hmac`
- **Base64**: Python标准库`base64`
- **随机洗牌**: Python标准库`random`

### 安全保证
- ✅ 防窃听: 内容使用自定义编码表加密
- ✅ 防篡改: HMAC-SHA256消息认证码
- ✅ 防重放: 序列号检测机制
- ✅ 健壮性: 支持丢失、重复、乱序

详细的安全分析和实现说明请参考 [SECURITY_REPORT.md](SECURITY_REPORT.md)
